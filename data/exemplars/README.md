## TWO PROTOCOLS, OPPOSITE RULES (grounded in the immersion research)

The immersion research (decisions-log, v3 overhaul; Holmes & Collins PETTLEP,
Green & Brock transportation, Ericksonian induction) found: **immersion comes from
ATTENTIONAL CAPTURE + SENSORY SPECIFICITY, and pre-imagery RELAXATION actually
REDUCES it.** That governs *imagination* (Family A) — but NOT meditation. So the
gold set splits into two protocols with deliberately OPPOSITE rules:

**IMMERSION protocol (Family A — being somewhere/someone):**
- Ericksonian "utilization" open (name what's already true), then HARD-CUT into the
  scene fast. Skip "release the day."
- COMMIT — no hedges. "Her hand finds yours," never "perhaps... / if it'll go there."
  Hedging kills immersion (research finding).
- Sensory specificity every beat; attentional capture, not somatic settling.
- Restraint (corpus-read finding) = don't depict the whole MOVIE, but DO commit to
  the sensations you name. Restraint ≠ hedging: guide attention FIRMLY.

**SETTLING protocol (meditation / wind-down / sleep):**
- Relaxation-led is CORRECT here — the goal is letting go, not transport. The
  immersion research's "no relaxation" rule does NOT apply.
- Soft, permissive language is fine and even right. Sleep trails off (no "eyes open").

→ Each exemplar is tagged with its protocol so we curate/train under the right rules.

**BUILD BOTH, FULLY — and let the USER pick (Sonali, 2026-06-01).** Both protocols
are first-class halves of the suite, built out big. And the immersion-vs-settling
choice becomes a USER-FACING FORK at intake, not a behind-the-scenes guess: ask the
user which experience they want — to be TAKEN SOMEWHERE (immersion) or HELPED TO
SETTLE (calm) — and route to the right protocol + ruleset. This is on-thesis: the
instrument doesn't presume, it asks. (It also cleanly resolves the conflict — no
auto-classifier guessing whether "a quiet beach" means transport-me-there vs
calm-me-down; the user tells us.) → intake gets a protocol-selection step.

## LENGTH: LONG (~1500-2000+ words) — but length through PROGRESSION, not padding

Corrected 2026-06-01 (Sonali): these are 10-15 minute SPOKEN sessions — read aloud
slowly with pauses between paragraphs, ~300 words is only ~3 min, far too short.
The full protocol (settle → journey → return) needs room to actually take someone
somewhere and let them dwell. Batch-1/2 drafts were too SHORT — Claude over-
corrected from the over-narration finding, wrongly conflating "short" with
"restrained." They're independent.

THE RULE: reach full length the RIGHT way — many DISTINCT moments / deeper turns —
NOT the lazy way the old model used (pad + repeat the same beat + over-describe).
- LONG + restrained + progressing = the target (hard, and exactly what the fine-tune
  must learn).
- LONG + padded/repeating/over-narrated = the old failure. Avoid.
So: keep the no-over-narration restraint AND the commit/no-hedge rule AND the
emotional-arc rule — and now also DWELL: more beats, each genuinely new.
